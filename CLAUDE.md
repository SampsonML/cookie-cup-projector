# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository state

The repo holds the raw stats spreadsheet plus a small static-site projector and a Python data pipeline that feeds it.

- `data/afl-fantasy-2026.xlsx` — DFS Australia AFL Fantasy 2026 stats (https://dfsaustralia.com/afl-fantasy-points/). Schema described below.
- `scripts/` — Python pipeline:
  - `parse_stats.py` — reads the xlsx, writes `docs/data/players.json`.
  - `probe_keeperfantasy.py` — diagnostic; dumps HTML + extracted Stimulus/React data blobs from keeperfantasy pages to `scripts/.cache/probe/` (kept for future schema changes).
  - `fetch_rosters.py` — scrapes the user's 14-team keeperfantasy league into `docs/data/rosters.json`. Reads each team page `/afl/<league>/<1..14>`, extracts the `data-lineup-lineup-value` Stimulus JSON, resolves each player against the xlsx by name + AFL team (with simple nickname fuzzy matching: Brad↔Bradley, Ollie↔Oliver, Matty↔Matt, Lachie↔Lachlan, etc.). Also reads `/matchup` once for the AFL team id→abbr map and the league's scoring formula.
  - `config.json` (gitignored) — `{ "league_id", "team_url_hint" }`.
  - `cookie.txt` (gitignored) — raw `Cookie` request-header value. Get it from DevTools → Network → any keeperfantasy request → Request Headers → Cookie.
- `docs/` — static SPA (vanilla JS, no build step). Designed for GitHub Pages serving from `main`/`/docs`.
  - `index.html`, `styles.css`, `app.js`
  - `data/players.json`, `data/rosters.json` (latter generated by scraper).
- `analysis.py`, `draft_analysis.py`, `plots/` — pre-existing exploratory analysis; not wired into the site.

### Run

Weekly refresh:
```bash
python3 scripts/parse_stats.py && python3 scripts/fetch_rosters.py
```

Initial setup:
```bash
pip install -r requirements.txt
cp scripts/config.example.json scripts/config.json
# then paste raw Cookie header value into scripts/cookie.txt (one line, no quoting)
python3 -m http.server 8765 --directory docs    # local preview
```

### rosters.json shape

Produced by `fetch_rosters.py`. Each team entry:

```json
{
  "id": "14",
  "name": "Naughty Dog Entertainment",
  "formation": { "starters": [...], "emgs": [...], "bonus": [...] },
  "roster": [
    {
      "kf_id": 523, "name": "Bailey Dale", "team_afl": "WBD",
      "positions": ["DEF"], "selected_pos": "DEF",
      "type": "starter", "starting": true,
      "playing_status": 1, "injured": false, "injury_desc": null,
      "cd_id": "CD_I...", "match_quality": "ok"
    }
  ]
}
```

Top-level keys include `has_captains`, `scoring_formula`, `round`, `afl_team_map`, `sport_fixtures` (AFL games for the round, with team abbreviations).

### Projection model

In `docs/app.js`, `project(p, mode)` returns one of three blends:
- `blend` (default): `0.5·L5 + 0.3·REG + 0.2·FP24`, falling back to whichever signals exist, then `FP23`.
- `l5`: last-5 average only (fallback chain L5 → REG → FP24 → FP23).
- `reg`: regular-season average only (REG → L5 → FP24 → FP23).

Team projection = sum of starter projections, with the top-projected on-field player getting a captain bonus (+1× their projection, i.e. counted twice).



## Data file: `data/afl-fantasy-2026.xlsx`

Single sheet `afl-fantasy-2026`, ~789 rows × 40 cols. One row per player.

**Provenance caveats** (stated in the file):
- Ownership % is current as of 21/01/2026.
- AFL games with <50% TOG (time on ground) are excluded from the AFL averages.

**Row layout:**
- Rows 1–7: metadata, source links, notes, glossary.
- Row 8: section banner row (groups columns into stat blocks).
- Row 9: column headers.
- Row 10+: player data.

**Column groups** (header row 9):

| Cols | Group | Columns |
|---|---|---|
| A–G | Identity / price | Player, Champion Data ID, Link, Team, Salary, Owned, Position |
| H–Q | 2025 AFL Fantasy | GMS, FP, MAX, 100+, 120+, CBA%, PPM, REG, L5, FIN |
| R–S | Prior FP averages | 2024, 2023 |
| T–W | 2025 VFL | GMS, FP, MAX, 100+ |
| X–AA | 2025 WAFL | GMS, FP, MAX, 100+ |
| AB–AE | 2025 SANFL | GMS, FP, MAX, 100+ |
| AF–AI | 2025 SANFL U18s | GMS, FP, MAX, 100+ |
| AJ–AM | 2025 Coates Talent League | GMS, FP, MAX, 100+ |

**Glossary** (from the file itself):
- `CBA%` — percentage of team's centre bounce attendances attended
- `PPM` — points per minute
- `REG` — regular-season average
- `L5` — average from rounds 20–24
- `FIN` — average in finals
- `GMS` — games played; `FP` — fantasy-points average; `MAX` — highest score; `100+` / `120+` — count of games over that score

**Reading the file:** because rows 1–8 are metadata/banners, load with the header at row 9 (e.g. pandas: `pd.read_excel(path, sheet_name='afl-fantasy-2026', header=8)`). Many cells are `None` for players with no data in a given competition — treat blanks as "did not play," not zero.
